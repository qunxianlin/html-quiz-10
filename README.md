# 10- HTML 基礎核心觀念互動測驗

精選 10 題 HTML 核心觀念考題，提供兩種答題模式（即時練習模式 / 模擬測驗模式）、即時音效回饋、詳細觀念解析與成績統計。

## 🌟 特色

- 🎯 **兩種測驗模式**：
  - **即時練習模式**：點選選項立刻給予對錯回饋與詳細觀念解析。
  - **模擬測驗模式**：全真模擬作答，交卷後統一結算分數與正確率。
- 💡 **詳細詳解**：每題均附有專業易懂的 HTML 觀念解析。
- 🔊 **Web Audio 音效**：內建合成音效（答對和弦音 / 答錯提示音），支援靜音切換。
- 🎊 **滿分慶祝動畫**：純 HTML5 Canvas 實現的 Confetti 彩帶碎紙特效。
- 📱 **響應式現代介面**：深色玻璃擬態風格（Glassmorphism），支援手機、平板與桌機。
- ⚡ **零外部依賴**：單一 HTML 檔案即可獨立運行。
